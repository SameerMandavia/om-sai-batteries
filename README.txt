OM SAI BATTERIES - AMARON ENQUIRY CATALOGUE
1. Keep `index.html`, `styles.css`, `script.js` and `om-sai-batteries-contact.vcf` together in one folder.
2. Open https://app.netlify.com/drop and sign in to your free Netlify account.
3. Upload the folder containing both files (or upload the ZIP if the interface accepts it; otherwise extract first).
4. Netlify will provide a public netlify.app URL.
5. Replace every `om-sai-batteries` placeholder in `index.html` with the actual Netlify site name, then redeploy.
6. Test the page on a phone, especially the Call, WhatsApp, Directions and Save Contact buttons.
7. Create a QR code whose destination is the final Netlify homepage URL, for example `https://your-site.netlify.app/`.
8. Print or share that QR code. Scanning it opens the website directly in the phone browser.
